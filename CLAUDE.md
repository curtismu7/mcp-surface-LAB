# mcp-surface-LAB

Demo-tier standalone app: Ping MCP gateway release claims (deck slides 36 to 39, release 2026-11-02): MCP Aggregate (the aggregate policy is the cap, enforced twice, lazy members, missing or unreachable members reported), entitlement-aware discovery (in-flight filtering of JSON, SSE and gzip), OpenAPI to MCP (real parser, mock backend), five credential modes with RS256 token pass-through, MCP Catalog, OAuth 2.1 with PKCE and CIMD, approval-gated creation. Simulated. **Every product claim is "Ping release claim, UNVERIFIED on our tenant"** (banner on every tab, presenter mode too).

- Run: `./scripts/run.sh` (http://localhost:7350). Test: `npm test` (server `node --test test/*.test.js`, a glob; web vitest against the real Express app; scripts). `npm run doctor`, `npm run reset`. Docker: `HOST_PORT=7350 docker compose up --build -d`. Node 26 only. Catalog id D106.
- Modes: **Mock** = tables (`server/src/mockTable.json`, `npm run mock-table`, plus `npm run talk-track`, `npm run content-pack`) generated from eight scripted scenarios run through the engine; a doctor check and a test fail on drift; read-only (409), except the pure `oaPreview`. **Live** = the engine on the visitor's actions. Both loopback-only, zero outbound (netguard + test).
- Core: `engine.js` (gateway pipeline, aggregate, policy) plus mixins `ops-*.js` (OpenAPI, credentials, catalog, OAuth, creation, aggregate config), `wire.js` (SSE/gzip framing and the fail-closed filter), `openapi.js` (bounded parser), `jwt.js` (RS256, RSA only, never EC), `oauth.js` (PKCE S256), `actions.js` (one dispatch: API, scenarios, tests), `scenarios.js`, `credentials.js` + `mask.js`, `service.js`, `app.js` (`POST /api/act/:op`).
- Rules that bite: typed text masked in every answer, state and log (`echo.test.js`); unknown keys refused without naming them; every user value used as a key is type-checked; honest HTTP statuses; writes synchronous per engine; caps refuse whole requests; a typed method is only stored if the gateway knows it; no fixed message may contain "token is", "secret:" and the like (the response mask would rewrite it; a test scans the source); every claim tagged deck / swagger name / lab reading / lab-invented / measured; "swagger" only for bare field names; UI: shared `web/src/styles/standalone-ui.css` vendored byte-for-byte, app CSS tokens only.
- Fix-pass rules (independent review): the schema expansion is budgeted while it runs; hop panes show a path template and argument names, never a substituted path; text is masked whole BEFORE it is tidied or cut (the shared masker decodes percent-encoding and reads through zero-width characters; `tidy` turns controls and bidi overrides into spaces after masking); `perform()` checks audit room BEFORE any non-pure action; a refresh token or code is never consumed by a refusal; the in-flight filter refuses a response in which a hidden name survives anywhere; a name may not equal an aggregate or its path; recordings never truncate (the call is refused); the lab always starts its own trace. `review-fixes.test.js` proves each.
- Settings: one shared `~/Development/.env`, `util.parseEnv`, only `MSF_LAB_MODE`, never a bare MODE. No k8s (deferred). Run check-drift, check-css and conformance by hand.
- Second review pass: names inside a specification are judged on their RAW text (`leaky()` in `openapi.js`) before they become identifiers; a header or parameter name shaped like a secret refuses the document; no wall-clock assertions (the schema bomb is proven by `expandedNodes()`); `amend` shares propose's pending-name rule; a refused request or pure preview holds no workspace slot (`runAction` adopts a new engine only if its snapshot changed); the CI doctor port must sit in 7350-7399 (`scripts/repo.test.mjs`).
- Third review pass: (superseded by the shared masker, see the next line); a list over its limit refuses the whole document (`LIST_CAPS`), and every list entry is paid for in the work budget (`charge`); no silent slice: a count of what is not shown; the hidden-name check is whole-name (`containsWholeName`); a missing file with an extension is a JSON 404 (`isPageAddress`); `boundaries.test.js` pins every stated limit with its literal number (N accepted, N+1 refused); pass-through diagram: the trust store sits under the backend.
- Shared masker (1.4.0, commit 9bc664a): `server/src/shared/mask.js` and `hygiene.js` are copied unchanged, never edited here (fix in ~/review-air/shared-masker, copy again, say the version in the commit). `mask.js` is the adapter (createMasker with `opaque()`: only mock-access/refresh/code-NNNN, the top-level traceId and `result.mockToken`; a `state.credentials` path rule; a story masker with key names off; `maskTyped` for hop panes and the audit); `credentials.js` keeps `cleanFree`, `maskText`, `MAX_FREE` over it. HTTP edge in `app.js`: one route table (405 with Allow, also `/`), charset 415, JSON 404, fixed error handler, `isPageAddress` for the page shell, `isCredentialId` for workspace ids (400 `bad_workspace`). A fixed lab message must not read like a secret (no "token is", "authorization codes:"). Tests: `corpus.test.js` (all shared corpora through the adapters), `named-leaks.test.js` (six known leaks), `sweep.test.js` (60 payloads over HTTP), `opaque.test.js`, `hygiene.test.js`.
